## Rules shared by A–K

Consumers authenticate the producer and authorize the specific action, tenant and resource. Keep the **caller** (workload or user performing an operation), **subject** (affected account), **device**, **login session** and **tunnel session/attempt** distinct. A client may identify a desired resource but cannot supply authority over it. Each card identifies context that is intentionally absent. All service credentials and environments have separate audiences and purposes.

A mutation carries a stable opaque intent or event ID scoped to its authenticated producer, tenant and operation. Reuse with changed input returns `conflict`. A repeated request returns the original disposition only while it remains safe. It cannot revive revoked state or allocate a second session. Match authoritative revisions under concurrency. A deadline can expire after commit. Reconcile by the same ID before retrying. Read-only checks may repeat within their freshness limits. Adapters need underlying I/O deadlines and cancellation that actually stops work.

Proposed error classes are `invalid`, `unauthenticated`, `denied`, `stale`, `replayed`, `conflict`, `capacity`, `unavailable` and `unsupported_version`. Restrict externally visible detail where it could enumerate another owner. Distinguish denial from retryable transport faults in private metrics. Neither outcome grants access. Prefer bounded, versioned messages and additive opt-in fields. Unknown required security semantics, ambiguous fields or unsupported versions fail closed. Deploy verifying readers before new writers. Record only coarse error, operation and sanitized evidence identifiers. Retention and deletion require an owner-approved purpose per data class, including backups.

### F/H/J · Proposed durable state

**PROPOSED logical records.** The lab uses one authority epoch with a strictly increasing global commit sequence. This avoids a different lock order for tenant rights and shared peer capacity. A peer receives an authenticated, scoped stream with its own contiguous sequence and covered global revision. Gaps in global numbers on a filtered stream are normal. Replication gaps are detected with the peer stream sequence, predecessor digest and high-water barrier. A new epoch requires explicit fencing, a verified checkpoint and complete tail before accepting comparisons.

All reference fields below are opaque, purpose-scoped and access-controlled. Scope foreign keys include tenant and owner where applicable. No natural identifiers, packet data, signed bearer bytes, payment fields or private keys belong in this ledger. The writer column identifies authoritative storage, including when the source domain remains external. **Horizon H** lasts until every potentially accepting reader, retry, credential, backup and replay path has expired, crossed a verified compaction checkpoint or been irrevocably fenced. H has no assumed duration. Unknown horizon blocks deletion. Restrictive floors outlive restorable copies; public telemetry contains no stable subject identifiers.

**R09 time contract (PROPOSED).** Verify the signed validity interval against a bounded trusted time interval at receipt. Arm the local gate against the earlier of the upstream validity limit and the boot-bound elapsed deadline anchored at challenge send. Charge worst-case drift and conversion error to the budget before arming. Reject uncertain time, backwards elapsed readings and expired replies. A clock reset or a new boot invalidates the allowance. A wall-clock correction, duplicate reply or transport rekey cannot extend it. QA separately accounts for observation error when evaluating the bound.

| State | Who can establish it and what it permits |
|---|---|
| `delivered` | Authenticated receiver reports message arrival. It may still be queued or discarded. |
| `committed` | Authority's linearizable transaction durably recorded the decision and outbox, queryable by original intent. This changes authorization. |
| `applied` | Matching Gateway boot durably incorporated the contiguous revision into policy and deny floor. Physical changes may still be pending. |
| `enforced` | Trusted local actuator reports the requested packet-path change completed for matching handles, generation and boot. Its report alone has no independent visibility of residual packets. |
| `confirmed_stopped` | QA correlates enforced/fence evidence with calibrated independent packet-stop observations for this session and interval. Native OS cleanup is recorded separately. |
| `unknown` | Missing, unverifiable, inconsistent or incomparable evidence. Preserve the last known restrictive facts, query same intent or reconcile and quarantine. A timeout changes knowledge, never grants authority. |

These are separate observations. Delivery can repeat after enforcement and ACKs can arrive out of order. Never infer a later phase by sorting timestamps or by receiving a larger sequence for another session. A lost stop ACK leaves central knowledge unknown until matching evidence is recovered.

### R07 · Concurrent histories and recovery obligations

| Interleaving or failure | Required result observable at authority and Gateway |
|---|---|
| 1. Admit commits first | One slot and intent. Subsequent revoke closes the session; an unactivated admission still needs a fresh positive activation. |
| 2. Revoke commits first | Reject admission on current floor, zero granted slots. |
| 3. Concurrent admit/revoke | One writer orders both; inspect committed sequence and test both outcomes above. No stale snapshot or independent domain writer decides the race. |
| 4. Two contenders for last slot | Serialize check and allocation for the shared generation including different tenants. Exactly one winner. Local resource failure releases only after safe closure. |
| 5. Same key, same inputs | Return original intent and latest disposition, one permit spend, one lease, one activation. |
| 6. Same key, other inputs | Conflict before mutation, even if only target generation, scope or device changed. |
| 7. Lost success response | Query original intent. Return historical result with current restriction; no second connection or lease. |
