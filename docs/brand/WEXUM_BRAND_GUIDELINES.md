# WEXUM — Справочник фирменного стиля

> **Статус:** эталон визуальной айдентики для новых бренд-материалов WEXUM.  
> **Дата фиксации:** 23 ноября 2026 года.  
> **Источник логотипа:** изображение, предоставленное основателем; SVG ниже получены контурной трассировкой этого изображения. Это не исходный редактируемый файл дизайнера.  
> **Область применения:** WEXUM и общие корпоративные материалы. Интерфейсы отдельных продуктов могут иметь собственные UX-правила, но должны сохранять согласованную идентичность.

## 1. Идея бренда

**Ключевые свойства:** премиальность, строгая геометрия, минимализм, точность, технологичность, уверенность.

- Фирменный знак — контрастная геометрическая монограмма, визуально читающаяся как **W**.
- Только плоские, чёткие формы; без теней, свечения, градиентов, объёма, металлизированных эффектов и декоративных текстур.
- В центре композиции — воздух, строгая сетка и смысловая иерархия.
- Сохранять читаемость на маленьком экране и при монохромной печати.

## 2. Логотип: что считать эталоном

**Слово WEXUM в логотипе — индивидуально построенная геометрическая надпись (wordmark), а НЕ набранное стандартным шрифтом слово.** Точное совпадение нельзя получить простым выбором шрифта или изменением кернинга.

| Файл | Назначение |
| --- | --- |
| [wexum-full-black.svg](assets/wexum-full-black.svg) | Полный логотип: чёрный, прозрачный фон |
| [wexum-full-white.svg](assets/wexum-full-white.svg) | Полный логотип: белый, прозрачный фон |
| [wexum-symbol-black.svg](assets/wexum-symbol-black.svg) | Только знак: чёрный, прозрачный фон |
| [wexum-symbol-white.svg](assets/wexum-symbol-white.svg) | Только знак: белый, прозрачный фон |

**Форматы:** для веба и макетов предпочтителен SVG. Для публикаций и платформ, требующих растровые файлы, используйте PNG с реальным альфа-каналом. Файлы с фоном должны иметь полностью непрозрачный фон без «шахматки».

**Ограничение трассировки:** контуры получены из растра и слегка аппроксимированы. При появлении утверждённого исходного векторного мастер-файла заменить эталоны через отдельное ревью; не смешивать несколько слегка отличающихся геометрий.

### Защитное поле и размеры

- Свободное пространство со всех сторон: **не менее 25% высоты монограммы** (рекомендованный минимальный отступ, не математическая характеристика исходника).
- Не обрезать элементы знака; не растягивать его по горизонтали или вертикали.
- Рекомендуемый минимум для одиночного знака — **32 px по ширине**, для полного логотипа — **160 px по ширине**, при условии визуальной проверки на целевом носителе.
- Для аватаров и иконок приложений использовать монограмму; для заголовков и юридически значимых бренд-материалов — полный логотип.
- На небольших размерах контролировать чёткость диагональных стыков и внутреннего негативного пространства.

### Запрещено

Нельзя перерисовывать W на глаз, печатать «WEXUM» вместо оригинального wordmark, подменять пропорции, вращать, добавлять окантовки, свечения, градиенты, узоры, иконки или текст внутрь самого логотипа.

## 3. Цветовая система

**У фирменного логотипа ровно два цвета:**

| Токен | HEX | Применение |
| --- | --- | --- |
| `--wexum-black` | `#000000` | Чёрный знак / фон инверсии |
| `--wexum-white` | `#FFFFFF` | Белый знак / светлый фон |

Разрешённые основные сочетания: чёрный на белом, белый на чёрном. Прозрачный PNG/SVG допустим в обеих версиях.

Для **служебного UI и второстепенной типографики**, но **не для заливки логотипа**, допускаются нейтральные оттенки: `#111111` (основной текст), `#666666` (вторичный текст), `#D9D9D9` (границы), `#F5F5F5` (нейтральная поверхность). Других акцентных цветов в корпоративной чёрно-белой айдентике не вводить без отдельного решения.

## 4. Шрифты

**Важное разделение:** оригинальный WEXUM wordmark существует как графика. Перечисленные ниже шрифты — **рекомендованные новые стандарты для сопроводительного текста**, а не установленные шрифты из исходного логотипа.

| Роль | Семейство | Начертания |
| --- | --- | --- |
| Основной интерфейс, кириллица/латиница, заголовки | **Manrope** | 400 / 500 / 600 / 700 / 800 |
| Цифры, метаданные, технические обозначения | **IBM Plex Mono** | 400 / 500 / 600 |
| Арабский текст | **Noto Sans Arabic** | 400 / 500 / 600 / 700 |
| Резервный вариант | **Noto Sans**, системный sans-serif | при отсутствии нужных глифов |

Для казахского текста обязательно проверить отображение всех нужных букв (ә, ғ, қ, ң, ө, ұ, ү, һ, і) в используемом файле шрифта и настроить fallback. Для арабского не применять латинский `letter-spacing`: это нарушает характер связного письма. Шрифты подключать из легальных источников и проверять лицензии; файлы шрифтов не хранить в этом справочнике.

### Типографическая шкала (рекомендация)

| Роль | Desktop | Mobile | Вес / интерлиньяж |
| --- | --- | --- | --- |
| Display | 48 px | 36 px | 700–800 / 1.12 |
| H1 | 40 px | 30 px | 700 / 1.2 |
| H2 | 32 px | 26 px | 700 / 1.25 |
| H3 | 24 px | 22 px | 600–700 / 1.3 |
| Основной текст | 16 px | 16 px | 400–500 / 1.5 |
| Подпись | 13 px | 13 px | 500 / 1.4 |
| Техническая метка | 12 px | 12 px | 500–600 / 1.45 |

- Заголовки: `letter-spacing: -0.02em` (кроме надписей-меток).
- Небольшие англоязычные метки в верхнем регистре: `letter-spacing: 0.06em`–`0.10em`; избегать длинных капслочных абзацев.
- Основной текст: `letter-spacing: 0`.
- Использовать **WEXUM** прописными буквами как юридически/брендово узнаваемое имя в идентификационном контексте; в связном тексте допустимо «Wexum». Именование отдельных продуктов сохранять согласно их официальным названиям.

## 5. Сетка и композиция

- Базовый шаг: **8 px**. Разрешён полушаг **4 px** для мелких деталей.
- Типовые промежутки: 8 / 16 / 24 / 32 / 48 / 64 px.
- Рекомендуемые горизонтальные поля: 20–24 px на мобильных, 40–64 px на десктопе.
- Преимущественно выравнивание по левому краю; центрирование допустимо для логотипа, обложек и коротких титульных композиций.
- Не использовать скопление декоративных элементов и рамок: сначала типографика, затем пространство и лишь потом разделители.
- Фото, иллюстрации и 3D-изображения не являются обязательными компонентами WEXUM-материалов. Для нейтральных корпоративных макетов предпочтительнее типографика и абстрактная геометрия.

## 6. UI-элементы

- Для корпоративных макетов — прямоугольные панели, сдержанные скругления `4–8 px` по необходимости.
- Чёрные основные кнопки на белом фоне или белые на чёрном; тонкая граница для вторичных действий.
- Достаточный контраст текста и фона; состояние фокуса должно оставаться видимым.
- Анимация, если нужна, короткая и функциональная; она не должна менять геометрию официального знака.

## 8. Как создавать новые фирменные материалы

1. Выбрать **готовый** SVG логотипа и нужный контрастный фон.
2. Использовать Manrope для новой информации; IBM Plex Mono — только для коротких технических полей.
3. Соблюсти сетку и защитное поле логотипа, не склеивать его с новым текстом.
4. Не создавать «новую надпись в том же шрифте WEXUM» — такого шрифта в этом паке нет; для названий новых продуктов применить согласованный текстовый стиль.
5. Экспортировать SVG или PNG с **реальной прозрачностью**. У прозрачного PNG проверить альфа-канал (RGBA, фон с alpha=0), а у фонового PNG — полную непрозрачность (alpha=255).
6. Проверить макет в двух темах, на мобильном размере и при уменьшении.
7. При существенных изменениях фирменных правил обновить этот документ отдельным PR, не меняя незаметно существующий знак.

## 9. Контроль качества перед публикацией

- [ ] Использован один из утверждённых SVG, его пропорции неизменны.
- [ ] Символ не перепутан с обычной буквой «W».
- [ ] Сочетание логотипа и фона строго чёрно-белое.
- [ ] Сопроводительный текст использует согласованные шрифты и размеры.
- [ ] Есть воздух вокруг знака и единая сетка.
- [ ] Прозрачность PNG проверена, шахматка не запечена в картинку.
- [ ] Кириллица, казахские буквы, английский и арабский протестированы там, где используются.
- [ ] Мобильный вид, доступность и контраст проверены.
