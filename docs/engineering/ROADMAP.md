# Execution sequence (not product release numbering)

**Architecture gate:** boundaries, contracts, product catalog, owner sign-off, risk register, legal/religious review workflow.

**VPN laboratory:** node/control-plane architecture, client prototype, test network with safe configurations, subscription entitlement model, monitoring, abuse management, legal and store eligibility checks.

**Platform core:** identity, organizations, permissions, delegated access, billing contracts, typed events, notification contracts and recovery procedures.

**Hub + first integrations:** isolated Hub shell, login, authorized product entry and resilient navigation; VPN only through an allowed native app integration.

**Data productivity:** Cloud → Plan → Knowledge → Work, each with consent and isolated failure paths.

**Expansion:** Secure, Search, Data, Flow, AI, Business, learning/publishing/developer modules after their security, cost and policy gates.

**Operational maturity:** load tests, backups, incident exercises, dependency reviews, mobile store compliance, third-party security assessment and measured SLOs.

No estimated completion date or guaranteed competitor parity is asserted. Track work in GitHub issues and PRs, not speculative progress statements.
